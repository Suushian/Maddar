# فاز ۳ — ماژولهای عملیاتی و Quick Add

این سند خلاصه پیادهسازی فاز ۳ است. تمام صفحات اکنون از Repositoryها و استریمهای Drift فاز ۲ تغذیه میشوند؛ هیچ عدد، دسته یا نمودار ساختگی در رابط وجود ندارد.

## آنچه پیادهسازی شد

### کارها (`lib/features/tasks/presentation/tasks_page.dart`)

- سه تب `امروز` / `صندوق ورودی` / `برنامهریزیشده` با فیلتر واقعی بر `due_date` و `focus_date`.
- چهار حوزه (کار و رشد، سلامتی، شخصی و خانه، یادگیری) با رنگ متمایز، و پرچم `مهم` (`priority = 1`).
- ستارهگذاری با محدودیت ۳ تمرکز در روز (پیام خطای دوستانه هنگام تلاش چهارم)، Swipe راست = انجام شد، Swipe چپ = انتقال به فردا، Undo پنج ثانیهای با `SnackBar`.
- حذف با تأیید کوتاه و Undo پنج ثانیهای. متد `TasksRepository.restoreTask` بهصورت UPSERT با همان `id` بازگردانی میکند.

### عادتها (`lib/features/habits/presentation/`)

- فرم تعریف عادت با نام، آیکون، رنگ و الگوی `daily` / `weekly` (انتخاب بیتهای هفته) / `alternate` (تاریخ لنگر).
- Heatmap قابل تنظیم ۳۰/۹۰ روز، اصلاح تیک روزهای گذشته با لمس، محاسبه Current/Best Streak و نرخ موفقیت شمسی از `StreakCalculator`.
- تمام محاسبات از `date_key` پایدار میلادی استفاده میکنند، بنابراین جابهجایی ساعت دستگاه ثبتها را جابهجا نمیکند.

### مالی (`lib/features/finance/presentation/finance_page.dart`)

- فرم تراکنش با کیپد عددی اختیاری (روشن پیشفرض)، دکمههای `+۵۰ هزار` و `+۱۰۰ هزار`، و امکان بازگشت به کیبورد سیستم.
- دستهبندیهای پیشفرض (خوراک، رفتوآمد، خانه، سلامت، خرید، تفریح، حقوق/درآمد، پسانداز، متفرقه)، جمع بودجه و قبوض پرداخت نشده، `Safe-to-Spend` و سهم روزانه از `BudgetCalculator`.
- Donut chart هزینههای ماه شمسی جاری و نمودار خطی ۷ روز اخیر، هر دو مستقیماً از تراکنشهای Drift.
- قبوض ثابت: تعریف، تیک «این ماه پرداخت شد» و ذخیره `last_paid_jalali_month`.

### ژورنال (`lib/features/journal/presentation/journal_page.dart`)

- Mood و Energy از ۱ تا ۵، Context Tags، میکروژورنال سهخطی با `date_key` یکتا (UPSERT همان ردیف را بهروز میکند).
- نمودار خطی نوسان روحیه، فقط بر اساس ماه شمسی جاری.
- ثبت از خانه و از صفحه ژورنال هر دو به همان `JournalRepository.upsert` میرسند.

### Quick Add (`lib/core/widgets/universal_quick_add.dart`)

- شیشه چهارتبه با `useRootNavigator: true`، تب پیشفرض متناسب مسیر جاری و بسته شدن صریح بعد از ذخیره.
- هر تب مستقیماً Repository مربوطه را صدا میزند؛ فاقد ردیف ناقص هنگام بسته شدن بدون ذخیره.
- اعتبارسنجی فرم، ارقام فارسی، Haptic خفیف و پیامهای فارسی.

### خانه و تنظیمات

- `TodayPage` به `todaySummaryProvider` متصل شد: ProgressRing، تمرکزها، عادتها، خرج امروز و خلق امروز همگی زندهاند.
- `SettingsPage` بودجه، زمان یادآور، قفل بیومتریک و بکاپ JSON (کپی/جایگذاری از طریق کلیپبورد) را واقعی کرد.

```bash
node /tmp/dart-parse2/parse.js lib test   # در صورت موجود بودن پارسر موقت
bash tools/verify_phase3.sh               # در محیط دارای FVM/SDK
```
