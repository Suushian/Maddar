# 🎨 سیستم طراحی مدار — بازطراحی خنثی

> تمام مقادیر از `AppColors`، `AppTheme` و `Motion` خوانده میشوند. عدد جادویی در ویجتهای feature ممنوع است.
> پیشنمایشهای مصوب در پوشه `design-preview/` نگهداری میشوند.

## ۱. فلسفه بصری

- **سکوت بصری:** سه رنگ خنثی ثابت، بدون رنگ معناگرا برای ماژولها، بدون گرادینت رنگی و بدون تگ قرمز/سبز.
- **شیشه و نرمی:** کارتها و نوار ناوبری از همان سه رنگ با شفافیت و `BackdropFilter(blur: 18–20)` ساخته میشوند؛ گوشهها گرد و سایهها کم_opacity از Ink.
- **ناوبری ثابت:** منوی پایین شامل ۵ تب آیکوندار + دکمه «ثبت» است. محتوای صفحه کاملاً بالای نوار قرار میگیرد و زیر آن پنهان نمیشود.
- **حرکت ملایم:** تنها opacity و جابهجاییهای کوچک؛ هیچ انیمیشن رنگی و هیچ حرکتی بالای ۲۲۰ms.

## ۲. سه رنگ ثابت

| توکن | مقدار | نقش |
|---|---|---|
| `paper` | `#EFEDE8` | پسزمینه روشن / متن در تم تاریک |
| `ink` | `#242521` | متن و سطح تیره / دکمه اصلی در تم روشن |
| `stone` | `#898D84` | رنگ تأکید، آیکون غیرفعال، حاشیه، شفافیتها |

تم تاریک (پیشفرض) و تم روشن تنها جایگاه این سه رنگ را عوض میکنند؛ رنگ چهارم وجود ندارد.
تمام رنگهای قدیمی (`brand`, `tasks`, `habits`, `income`, `expense`, `journal`) به `stone` نگاشت شدهاند تا از وابستگی featureها به رنگ جدا جدا جلوگیری شود.

### توکنهای مشتقشده (همان سه رنگ با alpha)

| توکن | تاریک | روشن |
|---|---|---|
| `bgPrimary` | `ink` | `paper` |
| `bgSurface` | `stone` @ ۱۱٪ | `stone` @ ۷٪ |
| `bgElevated` | `stone` @ ۱۶٪ | `paper` @ ۹۶٪ |
| `borderSubtle` | `stone` @ ۲۴٪ | `stone` @ ۲۲٪ |
| `textPrimary` | `paper` | `ink` |
| `textSecondary` / `textMuted` | `stone` / `stone` @ ۷۲٪ | همان |
| `brand` / `accent` | `stone` | `stone` |

`AppColors.neutralTones` و `AppColors.tone(i)` طیفهای خنثی مورد نیاز نمودارها، Heatmap و برچسبها را فراهم میکنند.

## ۳. تایپوگرافی

- فونت باندلشده **Vazirmatn** (وزنهای ۳۰۰–۸۰۰)، بدون درخواست شبکه.
- Display ۲۸/۸۰۰ · Headline ۲۲/۷۰۰ · Title ۱۸/۷۰۰ · Body ۱۵/۴۰۰ · Caption ۱۲/۵۰۰.
- اعداد فارسی با `FontFeature.tabularFigures()`.
- رنگ متن از `AppTypography.theme` و همان سه رنگ میآید.

## ۵. حرکت

| رویداد | رفتار |
|---|---|
| جابهجایی تب | ۲۲۰ms `easeOutCubic`، fade + translate ۱۰px |
| ورود صفحهها | ۲۲۰ms `easeOutCubic` |
| ورود کارتها | تأخیر ۴۰ms بهازای هر کارت (`Motion.entrance`) |
| فشار یک آیکون | ۲۲۰ms `easeOutCubic`، scale ۰٫۹۶ → ۱ |
| نشانگر تب پایین | ۱۸۰ms `easeOutCubic` |

`MediaQuery.disableAnimations` تمام موارد بالا را خاموش میکند.

## ۷. RTL و دسترسپذیری

- `Directionality.rtl` در ریشه حفظ میشود؛ ترتیب آیکونها در نوار از راست به چپ است و دکمه ثبت در سمت چپ قرار میگیرد.
- حداقل تضاد WCAG AA، اعداد و تاریخها فارسی، و متنها تا ۲۰۰٪ قابل بزرگ شدن بدون برش.
- تمام دکمهها دارای `Semantics` و حداقل هدف لمس ۴۸dpاند.

## ۸. پیادهسازی

- رنگها فقط از `AppColors` و تمها فقط از `AppTheme` میآیند.
- از `withOpacity` منسوخشده استفاده نمیشود؛ از `withValues(alpha:)` استفاده میشود.
- پیشنمایشها (`design-preview/`) مرجع بصریاند، نه اسکرینشات زنده.
